# Site Bortoluci Referência — versão local

## Abrir localmente

Abra `index.html` em um navegador. Não há dependências nem etapa de compilação.

## Estrutura

- `index.html`: conteúdo e estrutura da página.
- `styles.css`: identidade visual e versão responsiva.
- `script.js`: menu mobile e comportamento demonstrativo do formulário.
- `assets/`: logo e imagens originais do cliente, copiadas para o projeto.

## Antes de publicar

1. Validar textos, artistas e imagens com a Bortoluci.
2. Inserir links oficiais de Instagram, YouTube e WhatsApp.
3. Conectar o formulário ao workflow n8n/WhatsApp.
4. Subir os arquivos pela opção **Gerenciador de Arquivos** da Hostinger, na pasta `public_html`, após fazer backup do site atual.
